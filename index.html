Submenu de Pesquisa

Este menu apresenta duas opções de pesquisa:
No primeiro digite o nome do municipio e ao clicar no botão de pesquisa, o mapa se desloca para a posição do local pesquisado e um marcador é exibido.
No segundo, insira as coordenadas geográficas em graus decimais e ao clicar no botão de localizar, o mapa se desloca para a posição do local pesquisado e um marcado é exibido.

Submenu de Recorte Espacial

Este menu apresenta duas opções principais para a extração de dados geoespaciais:
1. Desenhar Área: Utilize as ferramentas de desenho disponíveis na interface (como polígonos, linhas ou retângulos) para delimitar o perímetro de interesse diretamente sobre o mapa. Aplique a uma camada cadastrada na pltaforma e receba o recorte em formato GeoTIFF (raster) e GeoPackage (Vetor)
2. Importar por Arquivo: Envie um arquivo vetorial compatível (como Shapefile, KML ou KMZ) para realizar o recorte dos dados em áreas que interseccionam este arquivo.

Submenu de Dados Externos

Permite integrar e visualizar fontes de dados externos e geoserviços no portal:
Insira o endereço (URL) de serviços compatíveis com padrões WMS para adicionar novas camadas para combiná-las com o acervo da plataforma. Exemplo de URL compatível:
https://geoservicos.inde.gov.br/geoserver/wms?service=WMS&version=1.1.0&request=GetMap&layers=BNDES:AP_2014&styles=&bbox=-74,-34,-27,6&width=297&height=245&tiled
=true&srs=EPSG:4326&format=image/png&transparent=true
